# Daniel Gyne — Releases

Official downloads for **Daniel Gyne – دانيال للنسائية والتوليد** (pregnancy follow-up, infertility & IVF clinics).

| Platform | File |
|---|---|
| Windows | `DanielGyne-Setup-<version>.exe` |
| Android (modern phones) | `DanielGyne-<version>-android.apk` |
| Android (all phones) | `DanielGyne-<version>-android-all.apk` |

Download from **Releases**. `version.json` is read by the application to notify clinics about updates.
Installing a new version over the old one keeps all patient data and the activation.
